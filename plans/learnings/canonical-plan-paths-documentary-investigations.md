title: "Canonical plan paths and documentary investigations"
date: 2026-10-05
category: tooling
component: general
tags: [planning, investigation, evidence]
file_type: rules
---

When a task mandates a canonical plan-path helper, run it exactly as specified before creating the plan and write only to its returned path. For investigation plans, keep reproduction documentary when execution is prohibited, then trace caller/assertion ownership before diagnosing. Preserve the explicit final-report path helper and fallback in the plan; distinguish current source from historical manifests and excerpts.
