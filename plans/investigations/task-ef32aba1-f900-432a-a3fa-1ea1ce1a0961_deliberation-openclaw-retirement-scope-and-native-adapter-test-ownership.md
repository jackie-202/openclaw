# Deliberation OpenClaw retirement scope and native adapter test ownership

## Verdict

**SAFE_SCOPED_REMOVAL** — the old bundled Deliberation implementation and its plugin-internal tests are retired. That does not justify deleting the retained Discord/Slack inbound-adapter tests wholesale. Those files still prove OpenClaw-owned dispatch ordering, deduplication, fail-closed termination, and absence of ordinary channel effects. Remove or rehome only the Deliberation implementation assumptions in those mixed tests; keep the host/native contracts they currently exercise.

This verdict covers a bounded future cleanup, not installed-package parity. The evidence does **not** prove that the current Discord/Slack loader tests execute `@openclaw-deliberation/plugin` as an installed external package. No tests, builds, installs, provider calls, or messages were run for this investigation.

## Minimal host boundary to retain

The smallest useful host contract is:

1. **Policy timing and event separation:** the host asks the generic synchronous policy before it can debounce/merge provider events; exclusive owners remain explicit (`src/plugins/hooks.ts:1023-1065`).
2. **Exclusive ownership is terminal:** the selected plugin alone receives the claim; `handled`, `declined`, missing plugin/handler, error, runner-unavailable, and ambiguous owner cannot fall through into the ordinary channel path (`src/plugin-sdk/channel-inbound.ts:53-87`).
3. **Native adapters preserve the boundary:** Discord stops before enqueue/activity/reaction/typing/session/dispatch/send; Slack stops before history/replies/thread resolution/tracking/enqueue/reaction. Duplicate native envelopes for one Slack event still produce one claim. Unconfigured traffic remains ordinary. Current queue tests also pin Discord/Slack source events to separate event IDs within a debounce window (`extensions/discord/src/monitor/message-handler.queue.test.ts:211-245,247-264`; `extensions/slack/src/monitor/message-handler.test.ts:225-254`).
4. **Transport seams stay owner-generic:** Slack registers the generic history runtime capability and maps native pages/messages/cursors; Discord/Slack outbound adapters retain the generic single-attempt send contract. None of these require Deliberation-specific policy in core.

Host adapter tests should not reassert Deliberation config normalization, configured-route matching, KM schemas/wire-body serialization, external source-history storage, final-delivery reservation policy, or plugin-private functions. Those are external package responsibilities and already have direct external tests.

## Smallest adequate test seam

For the remaining host assertions, a **generic test plugin/owner fixture** is the smallest adequate seam. It should declare an exclusive policy for one test route and allow each test to provide a handled, declined, or failing claim. The existing Discord and Slack real handler tests then verify native facts, claim ordering, duplicate behavior, terminal stop, and ordinary side effects without loading retired Deliberation source or duplicating Deliberation internals. Existing generic hook tests already own arbitration and result-state mechanics.

An **installed public external plugin fixture** is a separate optional gate if the product needs evidence that a released `@openclaw-deliberation/plugin` artifact is installable, discoverable, and registers its current manifest/hooks in OpenClaw. The current source-checkout fixture (`src/plugins/source-checkout-runtime.test.ts:53-77`) is only synthetic; the current installed-core package test checks that the retired plugin is _absent_ (`test/scripts/deliberation-package.e2e.test.ts:7-46`). Neither one proves the positive installed external package path. Do not vendor the external package or copy its implementation into a new generic fixture.

The current external `delivery-composition.test.ts` and OpenClaw native adapter tests are already the smallest seams for their respective outbound responsibilities. The Slack history adapter tests likewise directly cover the native provider bridge. No new engine is justified by the evidence.
