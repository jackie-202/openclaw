---
title: "Use the installed learning helper when repo-local path is absent"
date: 2026-08-17
category: tooling
component: general
tags: [skills, learnings, path, automation]
---

The documented repository-local `save-learning` helper path may not exist in every project checkout. When it is absent, use the helper from the loaded installed skill location instead of abandoning structured learning capture.

Verify the script location before rerunning so the same metadata and frontmatter generation flow is preserved.
