# Acceptance handoffs need an independent record

When a completion task must preserve parent evidence, do not backfill the parent
checkpoint. Create a follow-up handoff record under the new task ID that states
the exact fresh commands and outcomes, before/after hashes for excluded paths,
and complete owner-separated manifests. Reconcile the manifest with the live
dirty path list so required support fixtures are not omitted.
